TP2 - PowerShell

Alumno: Cristian

Materia: Programación para Seguridad Informática

Sistema: Linux Mint

Descripción

Dos scripts en PowerShell Core que cumplen los requisitos del TP2:

  • script1_saludo.ps1: Pide el nombre y muestra un saludo personalizado.
  • script2_paga.ps1: Calcula la paga según horas trabajadas y coste por hora.

Ejecución

pwsh -File ./script1_saludo.ps1
pwsh -File ./script2_paga.ps1
Nota: Adaptado de Windows a Linux Mint usando PowerShell Core multiplataforma con codificación UTF-8.
